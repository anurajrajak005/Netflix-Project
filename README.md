# 🎬 Netflix Data Analysis | Data Analyst Project

This project focuses on **exploratory data analysis (EDA) of the Netflix dataset** to discover meaningful insights about movies and TV shows available on Netflix.

## 📌 Project Objective

Analyze Netflix content data to understand **content distribution, genres, release trends, countries, ratings, and other key patterns** using Python and data analysis techniques.

## 🛠️ Tools & Technologies

* 🐍 Python
* 📊 Pandas
* 🔢 NumPy
* 📈 Matplotlib
* 📉 Seaborn
* 📓 Jupyter Notebook

## 🔍 Key Analysis

* Movies vs. TV Shows distribution
* Content released over the years
* Most common genres
* Top contributing countries
* Content ratings analysis
* Movie duration analysis
* Year-wise content trends
* Missing-value analysis
* Data cleaning and preprocessing
* Outlier and duplicate detection
* Visualization of important business insights

## 📊 Data Analysis Workflow

**Data Collection → Data Cleaning → Data Preprocessing → Exploratory Data Analysis → Data Visualization → Insights**

## 💡 Key Skills Demonstrated

* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Data Visualization
* Statistical Analysis
* Feature Understanding
* Business Insight Generation
* Python for Data Analytics

## 🎯 Project Outcome

The project demonstrates how a **Data Analyst** can transform raw Netflix data into meaningful visualizations and actionable insights that help understand content trends and audience-oriented patterns.
